# 다크 모드를 One Dark 로 — 원본을 베끼면 안 되는 이유

## 무슨 일이 있었나

다크 모드에 불만이 쌓여 있었다. 정리하면 두 가지였다 — **①가시성**(카드가 배경에 묻히고 블럭 안 본문이 안 읽힘) **②미감**(라이트 모드는 예쁜데 다크는 딱히 안 예쁨). 기존 다크는 순남색(oklch hue 265) 기조였는데, 차갑고 밋밋했다.

방향을 색 숫자로 논의하면 서로 감이 안 온다. 그래서 코드는 안 건드리고 **캔버스 겉모습만 딴 정적 HTML 시안**을 먼저 띄웠다 — One Dark(VSCode/Atom) 톤으로. 실제 반영 전에 "이 느낌이 맞나"를 눈으로 확정하고, 시안 위에서 대비·글로우·굵기를 몇 번 굴린 다음에야 코드로 옮겼다.

## 함정 1: 원본 팔레트를 그대로 쓰면 본문이 안 읽힌다

첫 시안에서 바로 걸렸다. One Dark의 본문/주석색(`#5c6370`)을 카드 본문에 그대로 썼더니 "글이 너무 안 보인다"는 피드백. 당연했다 — **그 색은 코드 *주석*을 일부러 흐리게 하려고 만든 색**이다. 키워드는 밝게, 주석은 흐리게가 에디터의 미덕이지만, 생각 정리 앱은 본문이 곧 내용이라 흐리면 안 된다.

```
본문색  #6b7484  (대비 ~2.5:1, 주석처럼 묻힘)
  → #b9c0cc  (대비 ~5.5:1, "읽는 글"로 보임)
```

교훈: **다크 테마를 앱에 가져올 땐 본문 텍스트를 준-전경색으로 못박아야 한다.** 라벨·메타(태그·저장시각)는 흐려도 되지만 본문은 아니다.

## 함정 2: 글로우가 다크에서 약하게 느껴진다

시급도를 오직 색(그림자 글로우)으로만 표현하는 게 이 앱의 규칙인데(질감 동일, 색=의미), 다크 바닥에선 파스텔 글로우가 힘이 빠졌다. 한 겹 흐린 광을 **2겹**으로 바꿨다 — 카드 가까이 진한 광 + 넓게 퍼지는 은은한 광. 색이 훨씬 또렷하게 뜬다. '미정(회색)'은 검정 그림자를 쓰고 있어 다크 바닥에선 아예 안 보였는데, 부드러운 흰 광으로 교체했다.

## 함정 3: 밝은 글자는 어두운 바닥에서 얇아 보인다

본문 색을 올렸는데도 "글씨가 얇아서 가시성이 떨어진다"고 했다. 이건 착시가 아니라 광학 현상이다 — 밝은 글자가 어두운 배경 위에 있으면 빛이 번져(halation) **같은 굵기라도 실제보다 얇아 보인다.** 라이트에서 딱 맞던 `font-light`(300)가 다크에선 얇게 느껴지는 것.

정석 해법은 **폰트를 바꾸는 게 아니라 다크에서만 굵기를 한 단계 올리는 것**이다(패밀리를 테마별로 바꾸면 글자 폭이 달라져 레이아웃이 흔들린다). `dark:font-medium` 한 줄. "다크에서만 고치는 게 웃기지 않나?" 싶지만 오히려 이게 테마별 보정의 정석이다.

## 절반만 토큰이던 다크 모드

코드를 열어 보니 다크 모드가 하이브리드였다. **CSS 변수 토큰 체계는 이미 잘 짜여 있었는데**(`.dark` 블럭의 oklch 팔레트, shadcn 컴포넌트가 이걸 씀), **커스텀 캔버스 컴포넌트들은 그 토큰을 우회**해 `bg-zinc-800`·`#151823` 같은 하드코딩 색을 삼항으로 칠하고 있었다. 그래서 헤더만 옛 남색으로 남아 캔버스와 톤이 안 맞는 seam이 생겼다("위에 배경이랑 색이 안 맞아").

그래서 두 갈래로 반영했다:

- **토큰(`globals.css` `.dark`)** → One Dark hex 로 교체. 바닥 `#21252b` ↔ 카드 `#2d323b` 밝기차로 블럭이 뜬다(가시성). 여기가 블럭·다이얼로그·shadcn 전부를 지배한다.
- **하드코딩 우회분**(header·canvas·auth-button·archive-dock의 zinc/남색) → One Dark 계열로 일괄 치환. 라이트 브랜치는 안 건드리고 다크 브랜치만.

## 정리

- **유명 테마를 가져와도 그대로 베끼면 안 된다.** 코드 에디터는 주석을 흐리게 하는 게 미덕이지만, 앱 본문엔 독이다. 맥락이 다르면 같은 색값도 의미가 다르다.
- **다크 모드 타이포는 굵기를 한 단계 올린다.** 밝은 글자는 어두운 바닥에서 halation 으로 얇아 보인다 — 폰트를 바꾸지 말고 `dark:` 굵기 보정.
- **글로우는 다크에서 2겹으로.** 한 겹 흐린 광은 어두운 바닥에서 힘이 빠진다. 진한 근접광 + 넓은 확산광.
- **색 방향은 숫자로 논의하지 말고 시안으로.** 코드 건드리기 전에 HTML 목업을 띄워 눈으로 확정하니 왕복이 빨랐다.
- **토큰 체계가 있어도 우회하는 하드코딩이 남으면 반쪽짜리다.** 팔레트를 바꿀 때 그 우회분이 seam 으로 드러난다.

롤백 지점은 `release/pre-dark-mode-onedark`. 정렬(줄 맞춤) 대개편은 같은 날 설계 스펙만 잡아뒀다 — 캔버스 전체 rows-first, x축은 "옆에 놓인 블럭들끼리 머리(윗변) 맞추기"로. 구현은 다음 사이클.
