# 완성해 놓고 잠가두기 — 개인 인사이트와 마스터 계정

## 무슨 일이 있었나

어드민 대시보드에서 유저별 드릴다운을 보다 보니, 이 화면은 유저 본인이 보면 더 재밌겠다 싶었다 — 내가 언제 생각을 펼치는지(집중 시간대 히트맵), 블럭이 어떤 시급도에 몰려 있는지, 연속 접속 며칠째인지. 그래서 **기능은 지금 다 만들어 두고, 공개만 나중에** 하기로 했다. 일반 유저에겐 "준비 중인 기능" 티저를 보여주고, 운영자 마스터 계정만 실물을 쓴다.

## 게이트는 UI 에만 걸면 반쪽이다

"준비 중" 처리를 프론트에서 조건부 렌더링으로만 하면, API 주소를 아는 사람은 그냥 호출하면 된다. 그래서 게이트를 두 겹으로:

- **UI**: 마스터가 아니면 티저 화면 (무엇이 나올지 목록 + "곧 만나요")
- **서버**: `/api/me/stats` 도 세션 이메일이 마스터가 아니면 403

전체 공개하는 날에는 이 게이트 두 줄만 지우면 된다. 기능 코드는 이미 완성돼 있으니까.

## 마스터 계정 — 판별은 항상 서버에서

운영자 계정 하나(학교 이메일)는 AI 월 한도(생성 300/정리 10)도 우회해야 했다. 구현에서 지킨 원칙 두 가지:

- **단일 소스** — 마스터 이메일 목록은 `lib/constants/master.ts` 한 곳. 시급도 색을 `urgency.ts` 한 곳에 모은 것과 같은 이유다. 흩어지면 언젠가 한 곳만 고친다.
- **판별은 세션에서** — 클라이언트가 "나 마스터야"라고 주장하는 게 아니라, 서버가 `auth.getUser()` 로 꺼낸 이메일을 확인한다. 클라이언트 게이트는 편의(티저 렌더링)일 뿐 권한이 아니다.

쿼터 우회는 `reserveAICredit` 에 이메일 파라미터를 추가해 마스터면 차감 없이 통과. 차감한 적이 없으니 환불 경로도 같이 건너뛴다 — 우회를 넣을 땐 **짝이 되는 반대 연산도 같이** 챙겨야 카운터가 안 꼬인다.

재미있던 질문: "다시 로그인해야 반영돼?" — 아니다. 세션에 권한을 심는 방식이 아니라 요청마다 이메일을 보는 방식이라, 코드만 배포되면 새로고침으로 끝난다. 세션 기반 권한과 요청 기반 판별의 차이가 체감되는 지점.

## insert-only 테이블에서 본인 통계 꺼내기

활동 통계의 원천인 `events` 테이블은 RLS 가 **본인 insert 만 허용**하고 select 정책이 없다(관리자 전용 read 만 있음). 유저가 자기 이벤트를 직접 조회할 수 없는 구조다. 선택지는 둘:

1. "본인 select 허용" RLS 정책을 마이그레이션으로 추가
2. 서버 라우트에서 **세션 검증 후 service role 로 본인 user_id 만** 집계해 반환

2번으로 갔다. 마이그레이션 없이 끝나고(프로덕션 DB 에 SQL 돌릴 일이 없다), 어차피 원시 이벤트가 아니라 집계 결과만 내려주면 되는 화면이라 서버 집계가 페이로드도 작다. RLS 를 뚫는 게 아니라 **RLS 가 막아둔 문을 서버가 신원 확인 후 대신 열어주는** 모양새.

블럭 통계(활성/완료율/시급도 분포/캔버스별 분포)는 서버에 묻지 않고 **지금 화면의 로컬 상태에서 바로** 계산한다. 저장 전 변경분까지 반영되고, API 왕복도 없다. 서버가 필요한 건 이벤트 기반 지표(접속 추이, 히트맵, streak)뿐.

## 번들 걱정 — recharts 를 캔버스에 태우지 않기

메인 캔버스 페이지는 이 앱의 전부라 번들이 민감하다. 인사이트 다이얼로그는 recharts 를 쓰는데, 이걸 정적 import 하면 차트 라이브러리가 캔버스 첫 로드에 딸려 온다. `next/dynamic` 으로 다이얼로그를 **열 때만 로드**하게 분리했다. 마스터 한 명만 쓰는(당분간) 기능이 모든 유저의 첫 화면을 무겁게 하면 안 된다.

## 정리

- **완성해 놓고 잠그는 방식**은 공개 시점을 마케팅 판단으로 미룰 수 있게 해 준다. 단, 게이트는 UI 와 서버 양쪽에.
- **권한 판별은 세션 이메일로, 요청마다.** 클라이언트 주장을 믿지 않고, 재로그인 같은 세션 갱신도 필요 없어진다.
- **insert-only RLS 는 서버 집계 라우트로 우회** — 정책 추가 마이그레이션 없이, 세션 검증 + service role + 본인 필터.
- **우회 로직은 짝 연산까지.** 차감을 건너뛰면 환불도 건너뛴다.
- **드물게 쓰는 무거운 UI 는 dynamic import.** 기능 하나 넣을 때마다 첫 화면이 무거워지면 안 된다.

롤백 지점은 `release/pre-personal-dashboard`. 다음은 다크 모드 마감 — 헤더/캔버스/경계선 색이 미묘하게 다 다른 문제와 블럭 본문 대비를 한 번 더 올리는 것.
