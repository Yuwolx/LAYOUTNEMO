# 🗺 Roadmap

LAYOUTNEMO의 현재 상태와 앞으로의 방향을 기록합니다.
이 서비스는 **완결된 결과물이 아니라 실험과 개선의 출발점**이므로, 이 로드맵도 상황에 따라 유연하게 조정됩니다.

---

- [x] 도메인 구매 + Vercel 배포 (`layoutnemo.com`)
- [x] 블로그 구조 재설계 + 다크 모드 적용 (2026-04-23)

- [x] 결(Facet) 용어 정리 + 한영 UI 전환 (2026-04-24)
- [x] 갈무리(Archive) UX 전면 개편 (2026-04-24)
- [x] 캔버스 팬 + Shift 연결 토스 + 관계선 시각 개선 (2026-04-26)

- [x] **AI 사용량 한도(쿼터)** — 무료 플랜 생성 300 / 정리하기 10, 원자적 차감·월 리셋·실패 환불 (2026-07-01)
- [x] AI 사용량 집계 버그 수정 — 이벤트 insert 가 `await` 되지 않아 요청이 안 나가던 것 (2026-07-01)

- [x] 결(zone) 삭제 동기화 분리 — saveCanvas 스냅샷 pruning 제거, 명시적 삭제로 멀티기기 유실 방지 (2026-07-01)
- [x] 클라우드 우선 로그인 병합 — 로그인 시 클라우드 기준, 이 기기의 로그아웃 후 변경은 백업+알림 (로컬이 클라우드를 조용히 덮던 문제 해결) (2026-07-01)
- [x] 안전장치 묶음 — 에러 바운더리(흰 화면 방지) + 보안 헤더 + 결/캔버스 삭제 확인창 + AI 입력 길이 상한(토큰 비용 방어) (2026-07-01)
- [x] 전체 백업 내보내기(JSON) — 로컬 사용자 데이터 유실 대비 (2026-07-01)
- [x] 블럭 검색(Cmd/Ctrl+F) + 선택 시 해당 블럭으로 캔버스 이동 (2026-07-01)
- [x] 헤더에 AI 사용량 표시(무료 플랜) + 관계선 렌더 성능 개선(O(n²)→O(n)) (2026-07-01)
- [x] 블럭 멀티 선택 — Ctrl 마퀴/클릭 선택 + 일괄 시급도·갈무리 + 같이 이동, 보라 선택 표시 (2026-07-02)
- [x] 대표 블럭(공지) — ⋮ 메뉴로 고정, 상단 배너로 항상 노출, 클릭 시 상세 (캔버스당 1개, metadata 동기화) (2026-07-02)
- [x] 공지 전용 앰버 색 통일(핀·링·배너 글로우) + 카드 높이 측정 무한 렌더 루프 수정(ResizeObserver deps) (2026-07-02)

## 📝 예정 (우선순위 조정 중)

- [ ] **동기화 견고성 (멀티기기 동시 편집 대비)** — 삭제 tombstone(지운 캔버스 부활 방지), 서버 시간 기준 충돌 판정, 저장 원자성/재시도 큐. 지금은 "한 번에 한 기기씩" 쓰는 전제에서 안정적이며, 동시 편집을 본격 지원할 때 필요.
- [ ] **협업 기능** — 공유 링크, 실시간 공동 편집
- [ ] **모바일 앱**
- [ ] **블럭 템플릿** — 반복되는 블럭 패턴을 저장/불러오기
- [ ] **반복 업무 자동 생성** — 주기적 블럭
- [ ] **통계 및 인사이트** — 시급도 분포, 결별 비율 등

## 🧭 방향성

- **"사고 공간"이라는 개념 자체를 계속 검증**
- 사용 경험을 바탕으로 **기능 확장과 구조 개선을 동시에** 탐색
- **로컬 우선, 사용자 통제감**을 해치지 않는 선에서만 AI 확장
