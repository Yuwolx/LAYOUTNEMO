# 🗺 Roadmap

LAYOUTNEMO의 현재 상태와 앞으로의 방향을 기록합니다.
이 서비스는 **완결된 결과물이 아니라 실험과 개선의 출발점**이므로, 이 로드맵도 상황에 따라 유연하게 조정됩니다.

---

## ✅ 완료

- [x] 데모 버전 구현 (2025-12-21)
- [x] 도메인 구매 + Vercel 배포 (`layoutnemo.com`)
- [x] 블로그 구조 재설계 + 다크 모드 적용 (2026-04-23)
- [x] 타입 안전망 복구 + 시급도 라벨/색상 정리 (2026-04-24)
- [x] 결(Facet) 용어 정리 + 한영 UI 전환 (2026-04-24)
- [x] 갈무리(Archive) UX 전면 개편 (2026-04-24)
- [x] 캔버스 팬 + Shift 연결 토스 + 관계선 시각 개선 (2026-04-26)
- [x] AI 생성 8초 자동 반영, 태그/외부 링크 지원, 헤더 로고 polish
- [x] viewport-aware 새 블럭 배치 + 기본/가이드 블럭 충돌 회피 (2026-05-28)
- [x] 캔버스 기본 배율 90%, 블럭 상세 확대, 결 선택 강조 유지 (2026-05-28)
- [x] 시급도 4단계 재정의 (`미정 / 여유 / 진행 / 시급`) (2026-05-28)
- [x] 저장된 가이드 블럭 자동 최신화 + 일반 드래그 Undo 히스토리 보강 (2026-05-28)
- [x] ESLint 9 + Next core-web-vitals 설정 정리 (2026-05-28)

## 🧭 방향성

- **"사고 공간"이라는 개념 자체를 계속 검증**
- 사용 경험을 바탕으로 **기능 확장과 구조 개선을 동시에** 탐색
- **로컬 우선, 사용자 통제감**을 해치지 않는 선에서만 AI 확장
