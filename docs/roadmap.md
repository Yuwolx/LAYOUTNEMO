# 🗺 Roadmap

LAYOUTNEMO의 현재 상태와 앞으로의 방향을 기록합니다.
이 서비스는 **완결된 결과물이 아니라 실험과 개선의 출발점**이므로, 이 로드맵도 상황에 따라 유연하게 조정됩니다.

---

- [x] **태블릿 터치 지원** — Pointer Events 전환(마우스·터치 단일 경로), 한 손가락 팬, ⋮ 메뉴 연결/복사(Shift·Alt 대체), 선택 모드 토글(Ctrl 대체), 터치용 항상 노출 어포던스 (2026-07-02)
- [x] **검토 기반 수정 묶음** — RLS 권한 상승 차단(`user_profiles` FOR ALL → 읽기+제약 삽입), OAuth 오픈 리다이렉트 차단, 결 삭제 시 블럭 재배정으로 FK 동기화 사망 방지, 팬 중 캔버스 영구 잠김 수정, 선택/연결 탭이 상세창 열던 문제 수정 (2026-07-03)
- [x] **반응형 헤더** — 로그인 시 태블릿/폰에서 상단바 줄바꿈 깨짐 수정 (좁은 폭에서 여백·최소폭 축소 + 비필수 요소 단계적 숨김, 데스크톱 유지) (2026-07-03)
- [x] **보안 의존성 업그레이드** — Next.js 16.0.10→16.2.10 (request smuggling·미들웨어 우회·CSP XSS 등 고심각도 15건+), lodash·ws audit fix. ai SDK 메이저 업그레이드는 별도 사이클로 분리 (2026-07-03)
- [x] **정리하기 삭제 블럭 보존 + Undo** — AI 제안 수락이 soft-delete tombstone 을 통째로 지우던 유실 경로 수정(전체 교체 → id 병합), 수락 1회 = 히스토리 1커밋으로 Undo 지원, 적용 필드 화이트리스트 (2026-07-03)
- [x] **결 삭제 시 블럭 재배정 UX** — 블럭 있는 결 삭제 시 "어디로 옮길까요?" 인라인 선택(미분류/다른 결), Undo 가 죽은 결 참조를 부활시키던 구멍 차단 (2026-07-03)
- [x] **하드닝 묶음** — admin 로그인 env 미설정 시 통과되던 구멍 차단 + timing-safe 비교 + 만료 있는 HMAC 세션 토큰(고정 토큰 대체), AI 라우트 maxDuration/fetch 타임아웃(크레딧 환불 생존)·max_tokens·프롬프트 크기 상한 (2026-07-03)
- [x] **헤더 가로 스크롤** — 실기기 피드백(태블릿 겹침) 반영: 폭이 모자라면 겹치는 대신 두 헤더 줄 모두 가로 스크롤(스크롤바 숨김·터치 스와이프), 저장시각은 데스크톱만 (2026-07-03)
- [x] **핀치 줌 + 휴대폰 기본 배율** — 두 손가락 핀치(중심점 기준, 30~200%), Ctrl/⌘+휠·트랙패드 핀치 줌, 휠 캔버스 팬, 휴대폰(<640px) 기본 60%, 배율 리셋 배지. 선택 모드 버튼·⋮ 어포던스는 any-pointer:coarse 판정으로(태블릿+마우스 구멍 차단). 실기기 검증 완료 (2026-07-03)
- [x] **PWA 지원** — 매니페스트 + 아이콘 세트 + 서비스워커(HTML network-first 로 배포 즉시 반영, 정적 자산 cache-first, API/auth 캐시 금지, 오프라인 폴백) + iOS 홈 화면 설치 안내. "모바일 앱"의 1단계 (2026-07-03)

## 📝 예정 (우선순위 조정 중)

- [ ] **동기화 견고성 (멀티기기 동시 편집 대비)** — 삭제 tombstone(지운 캔버스 부활 방지), 서버 시간 기준 충돌 판정, 저장 원자성/재시도 큐. 지금은 "한 번에 한 기기씩" 쓰는 전제에서 안정적이며, 동시 편집을 본격 지원할 때 필요.
- [ ] **협업 기능** — 공유 링크, 실시간 공동 편집
- [ ] **모바일 앱** — 1단계 PWA 완료(2026-07-03). 스토어 입점이 목표가 되면 2단계 Capacitor 래핑 검토
- [ ] **블럭 템플릿** — 반복되는 블럭 패턴을 저장/불러오기
- [ ] **반복 업무 자동 생성** — 주기적 블럭
- [ ] **통계 및 인사이트** — 시급도 분포, 결별 비율 등

## 🧭 방향성

- **"사고 공간"이라는 개념 자체를 계속 검증**
- 사용 경험을 바탕으로 **기능 확장과 구조 개선을 동시에** 탐색
- **로컬 우선, 사용자 통제감**을 해치지 않는 선에서만 AI 확장
