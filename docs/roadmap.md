# 🗺 Roadmap

LAYOUTNEMO의 현재 상태와 앞으로의 방향을 기록합니다.
이 서비스는 **완결된 결과물이 아니라 실험과 개선의 출발점**이므로, 이 로드맵도 상황에 따라 유연하게 조정됩니다.

- [x] **PWA 지원** — 매니페스트 + 아이콘 세트 + 서비스워커(HTML network-first 로 배포 즉시 반영, 정적 자산 cache-first, API/auth 캐시 금지, 오프라인 폴백) + iOS 홈 화면 설치 안내. "모바일 앱"의 1단계 (2026-07-03)
- [x] **미사용 ai SDK 제거 + 정리하기 기한 배선** — `ai` 패키지가 import 0건(라우트는 raw fetch)이라 메이저 업그레이드 대신 삭제로 취약점 체인 해소. 정리하기에 dueDate 전송 + 프롬프트 기준일 추가 — "기한 임박" 제안 카테고리가 처음으로 동작 가능해짐 (2026-07-03)
- [x] **동기화 견고성 1차** — 캔버스 삭제/초기화를 tombstone 으로(다른 기기 autosave 가 지운 캔버스를 부활시키던 통로 차단, `canvases.metadata` 활용·마이그레이션 없음), 클라우드 저장 실패 시 10초 재시도 + 온라인 복귀 즉시 재저장 + 재개 알림 (2026-07-03)
- [x] **하이브리드 정리하기** — 연결·기한·위치 제안은 클라이언트 룰베이스로 0초(쿼터 미사용), AI 는 결 오분류+인사이트 전담으로 축소(프롬프트·토큰 다이어트), 순차 모달 → 체크리스트 일괄 적용(전체 히스토리 1커밋 = Undo 1번), AI 실패 시에도 룰 제안은 유지 (2026-07-03)
- [x] **다크 모드 One Dark 개편** — 순남색 → One Dark(VSCode) 팔레트. 가시성(바닥/카드 밝기차로 블럭 부각, 본문 대비·다크 굵기 보정 halation 대응), 시급도 글로우 2겹 강화, 헤더·캔버스·크롬의 하드코딩색을 토큰/One Dark 로 통일. 색 방향은 코드 전에 HTML 시안으로 먼저 확정 (2026-07-08)
