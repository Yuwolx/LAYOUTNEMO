# 주요 기능

## 🧱 블럭 관리

- **자유로운 배치** — 드래그 앤 드롭으로 캔버스 어디든 배치
- **현재 화면 안 생성** — 새 블럭은 사용자가 보고 있는 캔버스 영역 안에서 생성되도록 `develop` 에서 검증 중
- **기본 블럭 충돌 회피** — 위치 추천 시 사용 설명서 같은 기본/가이드 블럭도 실제 블럭처럼 고려
- **Shift 연결 토스** — Shift 를 누른 채 한 블럭을 다른 블럭 위에 드롭하면 관계선 생성
- **선 클릭 삭제** — 관계선을 클릭하면 연결 해제
- **블럭 복사** — Alt/Option 키를 누르고 클릭하여 빠른 복사
- **갈무리** — 우하단 박스 아이콘으로 드래그해 잠시 치워두고, 갈무리함에서 다시 꺼내기
- **태그와 링크** — 블럭에 짧은 태그와 외부 URL 을 붙여 프로젝트 맥락과 참고 링크를 함께 보관
- **시급도 4단계** — 미정 / 여유 / 진행 / 시급으로 블럭의 상태와 긴급도를 색으로 구분
- **되돌리기/다시 실행** — 생성, 편집, 삭제, 갈무리, 일반 드래그 이동을 히스토리에 기록

## 🤖 AI 기능 (선택적)

- **스마트 블럭 생성** — 자연어로 입력하면 제목, 요약, 결, 기한, 시급도, 태그, 링크를 자동 추출
- **8초 자동 반영** — AI 제안 후 손대지 않으면 자동 생성. 클릭하거나 입력하면 즉시 취소
- **정리하기** — 여러 블럭을 살펴보고 AI가 배치/연결/시급도/결에 대한 제안을 카드 형태로 하나씩 보여줍니다. 적용/건너뛰기를 직접 선택하세요.
- **언제든 토글** — 헤더의 AI 버튼으로 ON/OFF. AI를 꺼도 모든 기능은 수동으로 사용할 수 있습니다.

## 🗂 다중 캔버스

- 프로젝트별로 **여러 작업 공간**을 만들어 분리
- `Cmd/Ctrl + K` 로 빠르게 전환
- 각 캔버스마다 독립적인 블럭과 결 관리

## ⌨️ 키보드 단축키

| 단축키 | 기능 |
|--------|------|
| `Cmd/Ctrl + N` | 새 블럭 만들기 |
| `Cmd/Ctrl + Z` | 되돌리기 (최대 50단계) |
| `Cmd/Ctrl + Shift + Z` | 다시 실행 |
| `Cmd/Ctrl + Y` | 다시 실행 |
| `Cmd/Ctrl + K` | 캔버스 선택 |
| `Space + 드래그` | 캔버스 이동 |
| `Alt/Option + 클릭` | 블럭 복사 |
| `Shift + 드롭` | 연결만 만들고 원위치로 복귀 |
| `Esc` | 다이얼로그 닫기 |

## 🏷 결(Facet) 관리

- **커스텀 결 생성** 및 이름 수정
- 결 추가/수정/삭제
- 상단 결 버튼을 드래그해 순서 변경
- 결을 클릭하면 해당 결에 속한 블럭들이 캔버스 위에서 강조됩니다.
- 선택한 결의 블럭 강조 배율은 `develop` 에서 더 또렷하게 조정 중입니다.

## 💾 데이터 관리

- **로컬 저장** — 모든 데이터는 브라우저 localStorage 에 즉시 저장
- **되돌리기** — 최대 50단계까지
- **휴지통** — 삭제한 블럭 10개까지 보관, 복원 가능
- **갈무리함** — 지금 보지 않을 블럭을 캔버스 밖으로 치워두고 필요할 때 복원

## 🌙 보기 옵션

- **다크 모드** — 헤더 버튼으로 라이트/다크 전환
- **연결 보기 토글** — 관계선을 숨기거나 다시 표시
- **기본 캔버스 배율** — 브라우저 축소 한 단계와 비슷한 90% 밀도를 `develop` 에서 검증 중
- **한영 전환** — UI 크롬과 기본 가이드/예시 블럭을 한국어/영어로 전환

## 🔐 로컬 우선, 클라우드 선택

- 기본적으로 **모든 데이터는 로컬 브라우저에 저장**됩니다. 로그인 없이 바로 사용할 수 있어요.
- 여러 기기 동기화와 구글 로그인은 v2 브랜치에서 실험 중이며, 아직 `master` 기준 제품에는 포함되지 않았습니다.
